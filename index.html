Questions fréquentes

Toutes les réponses avant de vous lancer.

Besoin d'une info supplémentaire ? Notre support est disponible pour vous accompagner à chaque étape.

Quelles versions d'Illustrator sont compatibles ? +

Logotyps fonctionne avec Illustrator 2021 et versions ultérieures. Nous recommandons la dernière version Creative Cloud pour bénéficier de toutes les optimisations de performance.

Comment fonctionnent les 7 essais gratuits ? +

Créez votre compte, installez le plugin et lancez vos projets. Chaque essai correspond à un export complet de projet. A l'issue des 7 essais, choisissez l'abonnement mensuel ou la licence à vie.

Puis-je personnaliser les dossiers générés ? +

Oui. Définissez vos règles de nommage, ajoutez des sous-dossiers spécifiques et sauvegardez vos presets pour tous vos clients.

Les mises à jour sont-elles payantes après la bêta ? +

Non. Tant que la bêta est active, toutes les mises à jour sont gratuites. Les abonnés bénéficient automatiquement des nouvelles versions stables.
